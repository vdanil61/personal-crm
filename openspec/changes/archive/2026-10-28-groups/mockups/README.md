# Макеты «Группы»

Смотреть макеты — на холсте: https://claude.ai/artifact/YQRLDPDummhR9bz8HDK6LK (холст закрытый: открывает только владелец и те, с кем он поделился через меню Share).

В этой папке — копия исходников холста, чтобы макеты хранились вместе с требованиями. Открыть эти файлы в браузере напрямую нельзя: они показываются только редактором холста.

Во всех экранах одни и те же данные: 14 человек и пять групп («Аналитики» — 3, «Друзья» — 6, «Знакомые» — 2, «Семья» — 2, «Теннис» — 4), поэтому числа на экранах совпадают.

| Файл | Экран |
|---|---|
| `Main.dc.html` | Главная на компьютере: фильтр по группам над блоком «Пора связаться», метки групп в строках списка |
| `Card.dc.html` | Карточка контакта на компьютере: строка «Группы» и список с флажками (открыт) |
| `Groups.dc.html` | Страница «Группы» на компьютере: создать, переименовать, удалить, «Отменить» |
| `Groups-Dialogs.dc.html` | Все диалоги страницы «Группы» разом, без нажатий: ошибка при создании, переименование, вопрос об удалении, сообщение с «Отменить» |
| `Form.dc.html` | «Изменить контакт» на компьютере: поле «Группы» |
| `Form-NoGroups.dc.html` | «Новый контакт» на компьютере, когда групп нет вовсе |
| `Phone-Main.dc.html` | Главная на телефоне: фильтр одной строкой, которую листают вбок |
| `Phone-Card.dc.html` | Карточка контакта на телефоне |
| `Phone-Groups.dc.html` | Страница «Группы» на телефоне |
| `Phone-Groups-Dialogs.dc.html` | Диалоги страницы «Группы» на телефоне разом |
| `Phone-Form.dc.html` | «Изменить контакт» на телефоне |
| `Phone-Form-NoGroups.dc.html` | «Новый контакт» на телефоне, когда групп нет вовсе |
| `canvas.json` | Как экраны разложены на холсте |

На экранах с синей меткой на холсте можно нажать Play — всё нажимается:

- главная: кнопки фильтра, метки в строках, «Связался», поиск; настройка `startFilter` (кнопка Tweaks) сразу ставит фильтр «Друзья + Теннис», «Без группы» или «Семья + Аналитики» (по ним никого нет — виден пустой результат);
- карточка: флажки в списке групп; настройки `popoverOpen` и `startGroups` (список закрыт, у контакта нет групп);
- страница «Группы»: создать, переименовать, удалить и «Отменить» (10 секунд); настройка `startState` открывает нужный диалог сразу;
- форма: отметки групп.

Если холст поменяется, копию здесь нужно обновить.
