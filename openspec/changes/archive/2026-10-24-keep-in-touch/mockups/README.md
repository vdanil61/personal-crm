# Макеты «Пора связаться»

Смотреть макеты — на холсте: https://claude.ai/artifact/AbVUpgB8A4UicGStVQw35h (холст закрытый: открывает только владелец и те, с кем он поделился через меню Share).

В этой папке — копия исходников холста, чтобы макеты хранились вместе с требованиями. Открыть эти файлы в браузере напрямую нельзя: они показываются только редактором холста.

| Файл | Экран |
|---|---|
| `Main.dc.html` | Главная на компьютере: блок «Пора связаться» с кнопками «Связался», поиск, список |
| `Card.dc.html` | Карточка контакта на компьютере: строка «Как часто общаться» |
| `Form.dc.html` | «Изменить контакт» на компьютере: поле «Как часто общаться» с открытым списком |
| `Phone-Main.dc.html` | Главная на телефоне: кнопки «Связался» — квадраты с галочкой |
| `Phone-Card.dc.html` | Карточка контакта на телефоне |
| `Phone-Form.dc.html` | «Изменить контакт» на телефоне |
| `canvas.json` | Как экраны разложены на холсте |

На главной на холсте можно нажать Play: «Связался» убирает человека из блока и показывает «Отмечено: …», «Показать всех» раскрывает блок, поиск прячет блок. Настройка `overdueCount` (кнопка Tweaks) меняет число просроченных: 0 — блока нет, 4 — без «Показать всех».

Если холст поменяется, копию здесь нужно обновить.
