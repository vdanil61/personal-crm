# Tasks

## Как работаем

TDD для кода приложения:

1. Пишем тест по сценарию спеки.
2. Запускаем `pnpm test` или `pnpm test:e2e` и видим, что тест красный.
3. Пишем код.
4. Тест зелёный.

Название теста — название сценария из `specs/`.

Нужен запущенный `docker compose up -d --wait`: база и Mailpit.

Шаги с пометкой **(владелец)** делает только владелец. Агент останавливается и говорит, что сделать.
