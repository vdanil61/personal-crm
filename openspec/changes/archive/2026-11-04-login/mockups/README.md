# Макеты «Вход»

Смотреть макеты — на холсте: https://claude.ai/artifact/Px8MqZ2kqG3ogJBrZk7VoL (холст закрытый: открывает только владелец и те, с кем он поделился через меню Share).

В этой папке — копия исходников холста, чтобы макеты хранились вместе с требованиями. Открыть эти файлы в браузере напрямую нельзя: они показываются только редактором холста.

| Файл | Экран |
|---|---|
| `Main.dc.html` | Страница входа на компьютере: поле «Почта», кнопка «Получить ссылку» |
| `Expired.dc.html` | «Ссылка устарела, запросите новую» с кнопкой «Получить новую ссылку» |
| `Home.dc.html` | Главная на компьютере: в шапке почта и «Выйти» |
| `Empty.dc.html` | Пустой список на компьютере: «Здесь пока никого нет», кнопка в блоке, наверху её нет |
| `Email.dc.html` | Письмо «Вход в Личную CRM» на компьютере |
| `Phone-Login.dc.html` | Страница входа на телефоне |
| `Phone-Expired.dc.html` | «Ссылка устарела» на телефоне |
| `Phone-Home.dc.html` | Главная на телефоне: почта и «Выйти» в шапке |
| `Phone-Home-LongEmail.dc.html` | Шапка на телефоне с длинной почтой: обрезается многоточием |
| `Phone-Empty.dc.html` | Пустой список на телефоне |
| `Phone-Email.dc.html` | Письмо на телефоне |
| `canvas.json` | Как экраны разложены на холсте |

На экранах входа (синяя метка) можно нажать Play: ввести почту и нажать «Получить ссылку» — появится «Ссылка для входа отправлена на …» или «Проверьте адрес почты» под полем. Кнопка Tweaks (`startState`) сразу открывает остальные состояния: «Слишком часто…» и «Не удалось отправить письмо…».

Что на макетах придумано без спеки (скажите, если не так):

- Пустой список оставляет поиск, счётчик «0 контактов», фильтр («Все», «Без группы») и кнопку «Группы». Из верхней части убрана только «Добавить контакт».
- Сообщения «Ссылка для входа отправлена…», «Слишком часто…» и «Не удалось отправить…» стоят под кнопкой, ошибка почты — под полем.
- На странице «Ссылка устарела» нет белого блока: заголовок и кнопка под ним.
- В письме сверху показаны «От» и «Тема» — это поля почтового ящика, а не часть письма. На сервере отправитель `noreply@mail.percrm.ru`, на компьютере владельца `v.danil903@gmail.com`.
- В письме добавлено слово «только один раз» к сроку 15 минут: так работает ссылка.

Если холст поменяется, копию здесь нужно обновить.
